# Famous Last Words: The Funniest Epitaph

The line, as carved:

> I said to the bear, "I come in peace." The bear's reply is carved on the back of this stone.

## Why this line

It is dying speech, quoted right on the stone: a man so confident in
diplomacy that he opened negotiations with a bear. The first half is the
famous last words themselves, deadpan and doomed. The second half is the
twist — the bear did reply, and the proof is physical: you are standing in
front of the evidence, and the punchline is on the other side of the very
stone you are reading. No explanation, no stage directions, one breath,
and it dares the reader to walk around the tombstone.

## How the program works

`main.py` (Python 3, standard library only, deterministic, offline) holds
the epitaph as a constant and writes it, UTF-8 and with no trailing
newline, to `/output/entry.txt`, creating the output directory if needed.
Every run produces byte-identical output: 92 characters, inside the
1–150 character gate.
