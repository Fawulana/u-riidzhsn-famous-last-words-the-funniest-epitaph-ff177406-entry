# Famous Last Words: The Funniest Epitaph

A one-line tombstone epitaph of famous last words, written by `main.py`
(Python 3.13, standard library only, deterministic, offline) to
`/output/entry.txt`:

> I asked God for a sign. The truck had one: STOP.

The joke turns on a single word: "sign" starts as a prayer for a divine
sign and lands as the road sign on the truck. 48 characters, no
explanation needed.
